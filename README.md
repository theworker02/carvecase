# carvecase

Carve encode/decode helpers for case payloads in pipelines.

**Site:** https://theworker02.github.io/carvecase/

## Install / run

```bash
git clone https://github.com/theworker02/carvecase.git
cd carvecase
node src/cli.js
node --test
```
